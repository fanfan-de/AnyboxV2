# Anybox Harness 三栏工作区

[文档入口](README.md) · [Web 客户端](web-client-design.md) · [Project Files](modules/sessions/project-files.md)

Anybox Harness 内部工作区分为项目导航、Thread View 与文件侧栏。Anybox 最左应用入口由宿主保留，三栏和工作区状态均由 Anybox Harness 浏览器入口管理，不增加 Nya 组件、Context、数据库连接或业务迁移。

## 布局与恢复

会话标题行从中栏顶边开始呈现。项目与会话侧栏、文件侧栏的两个折叠按钮放在活动会话标题行右侧；没有打开会话时，中栏顶边保留这两个按钮。工作区面包屑、独立顶部工具行和问号入口已移除。左侧项目栏最底部将紧凑执行设备选择器与只显示图标的 Anybox Harness 设置入口放在同一行；选择器保留屏幕阅读器标签和完整设备名称的 title 提示，“管理连接”作为设置分类呈现。窄屏先打开项目抽屉再进入设置，打开设置时释放抽屉焦点约束，关闭后将焦点返回仍可见的入口或项目栏折叠按钮。

左栏默认 240px、范围 200–360px；右栏默认 600px、范围 320–720px；分隔条仅占 1px，使用与宿主应用导航栏相同的单线边框，透明命中区向两侧各扩展 4px，支持指针与键盘调宽。停靠侧栏不重复绘制边框，悬停与键盘聚焦只增强线条颜色；抽屉保留自身边框与阴影。左右默认展开，中栏最低 320px。尺寸不足时临时缩小右栏、再缩小左栏；仍不足则右栏使用抽屉。Anybox Harness 挂载容器不超过 760px 时，两边使用互斥抽屉。自动尺寸适配不改写用户宽度和展开偏好；抽屉有 Escape、焦点循环、背景 inert 与关闭后焦点返回。

中栏沿用最多四个跨项目、跨设备会话的二叉分屏树。同一 Session 仍只有一个控制器。文件标签不进入 LayoutNode，也不计入会话面板上限。分屏空间不足时只显示活动面板，恢复空间后还原原树。

会话行的三个点打开悬浮操作菜单，提供右侧打开、下方打开和归档。菜单保留在应用侧栏的 DOM 与焦点边界内，以原生 popover 顶层显示，不撑高会话行且不受侧栏滚动容器裁剪；按按钮位置及窗口边缘调整，底部不足时向上展开。一次仅打开一个菜单，操作可用性沿用当前分屏和归档状态。方向键、Home/End 跳过不可用项；Esc 关闭并返回触发按钮，窄屏抽屉继续保留。外部点击、焦点离开、列表滚动、尺寸变化、项目收起、会话列表重绘或应用停用均关闭临时菜单。销毁工作区时删除菜单并撤销全部监听，不保存菜单状态。

文件侧栏随活动 thread 切换，各自保存树展开路径、目录请求宽度、标签、活动标签和阅读位置。左侧项目或设备选择不改变当前活动会话及其文件归属；无 thread 时提示选择会话，不创建会话或启动 Agent。文件栏的全宽路径顶栏始终显示会话所属设备与项目，有文件时继续呈现完整相对路径面包屑；目录刷新和折叠入口集中在此顶栏。顶栏下方为左侧阅读区和右侧目录树，两侧分别滚动。没有文件标签时阅读区显示选择文件的提示，目录位置不变；文件标签仍位于阅读区顶部，文件名、范围及当前文件或快照身份保持可辨认。

左右排列时阅读区与目录树之间有 1px 内部分隔线，沿用外侧分隔条的透明命中区和交互颜色，支持指针拖动和键盘调宽。目录请求宽度默认 220px、范围 180–360px；实际宽度同时受可用空间约束，为阅读区保留至少 280px。分隔条方向键每次调整 10px，Home 设为 180px，End 设为当前可用最大值，双击恢复 220px 默认请求宽度。文件栏自身宽度不超过 480px 时改为阅读区在上、目录在下，目录约占 38% 高度且不低于 120px，此时不显示内部调宽分隔条。目录收起时完全释放其占用空间，阅读区占满顶栏下方区域；展开入口仍位于路径顶栏。

现有布局、草稿与 pending 格式保持原状。查看位置增加可选 `viewMode`，沿用现有位置存储。`${layoutKey}.sidebars.v1` 仅保存左右栏偏好、按完整 scoped Project ID 记录的项目折叠状态和按 scoped Session ID 分组的文件视图描述，不保存正文、目录响应、筛选快照、游标或请求句柄。内部目录请求宽度按会话保存，旧记录缺失或无效时回退 220px；响应式适配只改变实际显示宽度，不改写已保存的内外栏请求宽度。不同设备的同名文件不会合并。项目首次默认展开；刷新网页、切换设备和恢复位置保留项目折叠状态，恢复选中项目不隐式展开，项目行直接从项目名称开始，不显示文件夹图标或独立折叠箭头；点击项目行选中该项目并切换其会话展开状态，新建会话则展开对应项目。不同设备的同名项目独立保存，设备过滤或部分项目列表不清除其他设备偏好；旧记录缺少项目折叠字段时仍默认展开，无效字段独立忽略。损坏的边栏记录独立回退；存储失败提示，但不禁止使用。关闭会话保留描述供重开，刷新重新读取当前文件，历史标签仍读取快照。

## Thread 对话与轨迹

分支导航行右侧提供“对话 / 轨迹”切换。默认对话只显示当前分支的消息与实时回答，并保留消息内的思考、工具过程及引用；轨迹以紧凑连续表展示本会话所有分支的 Run，按开始时间与 ID 稳定排序，保留运行分组、起点标识、状态和真实执行顺序。顶部提供三通道概览、耗时切换、轮次/调用折叠和已加载展示内容搜索，点击行查看明细；左侧分支控件替换为“本会话全部运行”，无记录时显示空态。入口数量包含 `running` 与 `cancelling`，为零时隐藏；窄面板只显示数字，两个切换入口保持可见。

查看模式按 scoped Session ID 存入现有位置记录，`viewMode` 为 `dialogue` 或 `runs`。缺失、旧记录及无效值回退对话；刷新与关闭重开恢复模式，但不恢复隐式自动跟随。普通节点导航保留模式，“查看回答”明确切回对话并定位成功结果，“查看步骤”保留关注行为并定位相应运行首行与明细。对话保留失败、取消及中断的简短提示和对应记录入口，不生成成功节点；归档及旧格式会话均可浏览两个视图，写入限制不变。

对话、轨迹和输入框持续挂载，通过 `hidden` 与 `inert` 切换。记录模式隐藏输入框但保留草稿；切换不 detach 控制器，不取消在途 Run，也不销毁协议 Turn。两个滚动容器分别保存 `{ dialogue, runs }`；首次进入记录定位最近 Run，之后恢复各自位置，记录更新不强制滚动，选中行和折叠状态保留。明细在桌面显示于右侧，640px 以下面板改在下方。历史读取共享两个并发槽，尚未加载、失败及截断分别提示；搜索非空渐进补读历史并显示范围，完整长历史分页与全历史搜索另行实现。隐藏或零尺寸面板不写入滚动位置。模式切换不改变分支、关注对象或自动跟随，运行在后台完成时仍按原有跟随规则更新对话位置，同时保留当前记录模式。

## 目录树与资源归属

目录树经 Session 固定项目，由已有 Project Files 组件拥有文件系统资源。根用空相对路径表示；其余路径沿用现有校验。包括点文件和 ignore 文件，排除既有版本控制元数据及依赖目录；仅列普通目录和文件，不跟随符号链接。

旧 `dialogue-v1` 与归档会话也可浏览目录及预览当前文件；引用按钮保持禁用，不开放旧会话的资源快照、图片或继续执行。Session 为项目只读浏览显式区分访问边界，避免旧会话的原生历史限制误拦目录请求。

按展开逐层读取目录，每页最多 100 项，扫描预算 1,000 项或 200ms；空页仍可能有下一页。前端对已加载条目按目录优先与名称排序，提供加载更多、目录级重试和手动刷新。目录顶部的筛选输入高 28px，树行高 24px；筛选仅匹配已加载目录快照中的名称与相对路径，临时展示匹配祖先及已加载的匹配子项，同时保留分页、错误和重试入口。筛选输入不改变持久展开集合，不新扫目录、不发起新的文件搜索请求；用户显式展开、加载更多或重试仍通过原目录客户端读取。清空后按原展开集合显示，不把筛选结果当作项目全部文件，也不增加文件监视器。前端可保留刚加载的 `FileTreeEntry[]`，用于目录收起后的临时筛选展示；缓存不含服务端游标或分页句柄，目录 close 仍取消读取并释放游标，会话或设备切换、整个文件区隐藏及刷新时清除缓存。成功重读包含空目录时替换旧缓存，避免已知过期条目重新出现。

目录、文件类型和操作图标采用 Microsoft Codicons 的本地 SVG 副本，固定来源版本与许可见[图标说明](../web/apps/agent/icons/README.md)。图标经 Anybox Harness 的精确静态资源图注册，通过同源图片呈现；文件名和动作仍由文本与无障碍名称说明，不依赖图标传达文件归属或快照身份。

树页包含 `cursorId`、`page`、相对目录 `path`、`entries` 和 `nextPage`。游标绑定 Session、项目、相对目录、HTTP actor 与组件代，不持久化。最多 16 个存活游标，60 秒空闲回收；扫描与现有文件操作共享并发 2 队列。结束、取消、显式关闭或过期均关闭句柄；清理失败停止新的树浏览准入，并由组件关闭报告。

执行 API 为 `/api/v1/sessions/:id/project-files/tree/open`、`page`、`close`，均使用 POST，分别接收 `{path}`、`{cursorId,page}`、`{cursorId}`，owner 来自受信 HTTP context。网关接纳精确路径，每次请求固定连接版本、实例与服务代。HTTP、认证撤销、Session 和组件关闭均取消并等待相应读取和游标清理；不把 result 就绪当作资源退出。响应不暴露绝对路径或系统异常。

## 预览与引用

目录文件、输入框 @ 候选、附件草稿和历史文件引用统一打开右侧标签。当前文件按路径去重，快照按用途与 snapshotId 去重，两种来源不合并。正文用 textContent 呈现，不执行文件内容。

源文件 10 MiB、单预览/引用 64 KiB、每轮 8 个及合计 256 KiB 限制继续有效。非 UTF-8、二进制和超限文件可列在树中，读取时返回明确限制。超限预览不把前缀作为附件；选择行范围后重新预览。当前预览不持久化，引用保存路径/范围，发送时才准备快照。历史与编辑默认复用快照，更新当前文件必须显式操作，不改写历史。

树文件引用在点击时固定当前草稿位置；@ 和已有附件编辑固定原父节点与来源。控制器同步校验 loading、busy、pending、只读状态、父节点和附件身份，去重后一次更新文字与文件。@ 只删除仍匹配的原片段，不按旧偏移删除后续输入。

切换 thread、标签、范围、关闭或隐藏时取消展示读取，递增请求代次并拒绝迟到结果；目录游标显式关闭。隐藏应用结束临时菜单和零尺寸布局写入。关闭标签、右栏或界面不取消 Run、准备批次，也不删除草稿。侧边对话、浏览器、全文编辑和语法高亮不在首期实现，没有占位页。

## 验证

行为测试覆盖目录分页、安全归属、取消与真实退出、树响应竞态、引用确认及边栏恢复。隔离项目文件与工作区测试宿主验证 1440px、1024px、390px、容器缩放、分屏、抽屉键盘操作、引用、刷新恢复和应用切换。完整入口为根 `npm run check`，不使用真实模型、系统凭据或用户业务库。

文件布局的浏览器验收检查全宽路径顶栏中的设备与项目归属、长路径面包屑、集中刷新与折叠入口、左右布局与独立滚动、无标签时的阅读提示、多标签横向滚动、类型图标与选中态。内部目录调宽应覆盖指针拖动、方向键 10px 步长、Home/End、双击默认、可用宽度约束、会话独立保存及旧记录恢复；窄布局不提供内部分隔条，目录收起后阅读区使用全部可用空间。筛选应展示已加载匹配项及其祖先、保留加载更多与错误重试、保持输入焦点，并验证没有额外目录读取且清空后恢复原展开集合。窄屏抽屉仍检查键盘可达性和横向溢出；切换会话、刷新和关闭重开仍保持设备隔离、当前预览与历史快照身份及原有读取清理边界。

Thread 视图切换的验收应覆盖默认及损坏模式恢复、全会话记录、活动数量、草稿及独立滚动保留、持续挂载的协议 Turn、切换期间在途运行及自动跟随；检查成功、失败、取消、中断和实际工具结果，以及“查看回答”和“关注过程”的定位。浏览器验收使用同一隔离宿主，覆盖 1440px、1024px、390px 与四分屏，检查两个入口可见、键盘切换、无横向溢出、流式回答、应用切换和关闭重开。

目录与 HTTP 生命周期测试位于 `tests/project-file-tree.test.mjs`、`tests/project-file-tree-http.test.mjs` 和 `tests/host-access-lifecycle.test.mjs`；前端状态与竞态测试位于 `tests/sidebar-layout.test.mjs`、`tests/file-tree-client.test.mjs`、`tests/file-sidebar.test.mjs`、`tests/session-client.test.mjs` 和 `tests/session-view.test.mjs`。

构建后运行 `node tests/helpers/workspace-browser-host.mjs`，打开输出的 `qaUrl`。该页面通过同源测试代理提供真实 iframe 容器，可选择三种验收宽度或连续调宽；目录中的 Notes 仅为独立测试应用，用于验证切换后 Anybox Harness 的草稿与文件视图保留。退出测试宿主会关闭代理、客户端和执行端，并清理临时数据库与项目目录。

测试模型输出受控流式文本，输入包含 `hold` 时保持运行以便验收取消，独立单词 `fail` 触发受控失败；不调用外部模型。

使用 `ANYBOX_TEST_LEGACY_SESSION=1 node tests/helpers/workspace-browser-host.mjs` 额外建立隔离的旧格式会话，验证目录展开、当前文件及范围预览，以及引用按钮仍禁用。该选项只写测试宿主的临时库。
