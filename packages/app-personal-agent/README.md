# Personal Agent

`@anybox/app-personal-agent` 是 Anybox 的独立应用，稳定 ID 为 `personal-agent`。首版用于验证“配置同级 Agent → 独立交流或建立任务 → 多次推进 → 委派 → 管理成果”的真实使用流程。

从仓库根运行：

```sh
npm run personal-agent
```

打开终端打印的本机地址，从 Anybox 菜单进入 Personal Agent。默认完整客户端发行也提供该应用入口。第一次打开时已有“我的 Agent”；在应用的模型设置中填写模型协议、基础 URL、远端模型 ID 和可选 Key，再编辑 Agent 选择该执行配置。这里的模型配置和 Key 独立于 Anybox Harness。

首版支持：

- 同级 Agent、稳定身份与配置修订；默认打开偏好；仅由用户填写的记忆和 Skills 指令文本。
- 独立对话和任务；不同任务并行，一个任务同一时间只接受一次推进。
- 每 Run 固定最新 Agent 配置、实际文本上下文、模型配置版本与执行结果；显式取消等待实际资源退出。
- 手动标记进展、等待条件和任务完成；向其他 Agent 移交独立任务，保留来源及下游状态；取消原任务不取消下游任务。
- 保存、查看及下载文本成果，关联执行来源。
- 上下文字符预算用尽后暂停；用户主动开始新上下文段，旧历史仍保留。新段仍携带当前任务目标，旧段内容不自动转入。
- 重启把未结算 Run 标记为 interrupted，等待用户显式推进，不自动重发未知模型请求。

该版本固定运行在当前客户端实例，执行为一次完整文本模型调用。Skills 是用户维护的指令文本；尚无外部 Skills 文件加载、工具调用、文件/终端执行、自动委派、定时唤醒、跨设备绑定/交接或共享资料授权。任务完成、等待和成果保存由用户明确操作，模型生成文本不会自动改变任务状态。首版为中文界面，暂不接入宿主语言偏好。应用拥有文本上下文，不保存或恢复协议私有 continuation。

应用只声明 client 角色，在客户端已有 Nya 根安装自己的工作区与 HTTP 组件，按需装配通用 Models。SQL 经 `storage.sqlite` 能力访问，业务表有独立迁移域；Models 用应用独立 JSON 文件和 Vault 命名空间。没有依赖 Harness、Claude Agent 或宿主内部业务。`anybox.app.json` 支持正常构建可直接安装目录，准备工厂只返回注册，不打开任何资源。

配置、API、生命周期与验证入口见 [Personal Agent 手册](../../docs/modules/personal-agent/README.md)。
