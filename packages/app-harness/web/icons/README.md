# Anybox Harness UI icons

These assets provide disclosure arrows and standalone refresh, file-tree collapse, and close controls. File names and text-labeled actions use text without decorative type icons.

These unmodified SVG icons come from [Microsoft Codicons](https://github.com/microsoft/vscode-codicons/tree/e59d6bafa72517563ce8b4cdc1e7fd8d48923357/src/icons), revision `e59d6bafa72517563ce8b4cdc1e7fd8d48923357`.
