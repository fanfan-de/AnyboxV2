# Agent Note: 每次独立变更在仓库记录方向

Status: implemented

## 问题

用户要求参考 GitHub DeepSeek 仓库的文件夹治理方式，在 Anybox 仓库记录每次变动的方向。现有组件手册、产品决策表与阶段计划分别记录当前行为和部分历史，缺少统一的逐次变更方向入口；仅在聊天中解释原因无法让后续协作者直接追溯。

## 决策

采用 `.agents/notes/{状态}/{类别}/YYYY-MM-DD-topic.md`，参考 DeepSeek Harness 的状态与类别分层。每个独立评审目标一篇，记录问题、方向及理由、实际比较的方案、影响和验证入口。按用户要求覆盖代码、配置、脚本、资源、测试、纯文档与小型调整；同一轮目标内迭代共用记录，后续独立变更新建并链接前项。

根协作说明要求在交付前完成记录；仓库 README 和文档入口提供导航，子目录协作说明约束状态和维护。仅创建当前有内容的 `implemented/bug-fix` 与 `implemented/process`，格式示例放在目录说明中，其他状态和分类按需建立。当前功能手册继续在 `docs/`，Git 继续保存具体改动。

本次补录此前同一聊天完成的模型无新内容超时与失败内容保留、工具请求有界纠错，两项均以本次建档日 2026-11-11 命名，依据当前源码、行为测试和本机检查输出。未调查工作区内其他未提交变更的来源，不为其编造历史记录。

## 备选方案

**仅用 Git 提交信息或聊天记录。** 不能在仓库里稳定承载问题、决策理由、验证限制及后续替代关系，不满足用户要将方向记录在仓库中的要求。

**把每次变更追加到根 AGENTS 或单个大文件。** 会混合当前规则与历史，增加并行编辑冲突；采用短规则加分文件记录。

**完全复制 DeepSeek 的豁免和工具链。** DeepSeek 允许机械或局部调整不建 Note；用户要求记录每次变动，因此本仓库覆盖这些改动。当前不引入双语副本、哈希封存器或自动门禁，保持中文单份规则。

## 影响与代价

每次变更增加一份简短方向记录及交付检查成本；小改动允许简写，同一目标不按文件、提交或测试次数拆分，记录自身修订不递归建档。方向被替代保留理由和关联，当前接口说明不重复抄写。

本次治理改动只涉及 Markdown 文件，不改变运行行为、数据格式、依赖或服务配置；无需重启服务。规则通过协作说明执行，尚无自动检查证明每项源码变更都具备对应记录。
