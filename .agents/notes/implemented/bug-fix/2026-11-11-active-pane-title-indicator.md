# Agent Note: 用标题圆点替代会话顶部活动横条

Status: implemented

## 问题

用户认为会话面板顶部贯穿整栏的深灰活动横条过于粗重，要求更换呈现形态。

## 决策

删除会话标题栏默认及活动状态的顶部 inset 阴影，标题栏保持同一平整背景。沿用现有 `.active-pane`，仅在当前面板标题左侧显示 4px 中性灰圆点，并将标题颜色从次级文字色加深为主文字色。所有标题统一预留 10px 标记空间，字重固定为 500；切换标记只改变颜色与可见性，不引入标记占位或文字宽度变化。同步现行 Web 设计说明。

## 备选方案

未将横条改为另一条长下划线，以免继续突出横向边界；未采用活动标题加粗，因为字形宽度变化会影响长标题的省略位置。圆点使用空内容伪元素，不新增业务状态、焦点或 DOM 交互。

## 影响与代价

保留多面板的活动指示、标题拖动、关闭按钮、现有聚焦和共享侧栏控件移动逻辑。标题固定增加 10px 内边距，略减少可显示的文字宽度；长标题继续省略，窄面板沿用既有元信息隐藏规则。不改变资源、持久布局或生命周期。此方向替代前两项界面调整中保留顶部横条的呈现决定，背景配色与细分隔线决定仍有效。

## 验证

- 使用现有 Node 24 工具链执行 `npm run build --workspace packages/app-harness`，通过。
- `node scripts/verify-web-assets.mjs` 通过。
- Chrome 临时样本直接使用 `session-view.ts` 的标题栏 HTML 与实际宿主/应用 CSS：640px 和 320px 面板中，标题栏 `boxShadow` 均为 `none`，只有活动面板显示 4px 圆点，标题颜色分别为 `#222` 与 `#686868`。在固定标题 DOM 上来回切换 `.active-pane`，标题、元信息、状态与关闭按钮的边界以及标题字重保持不变；长标题省略且面板无横向溢出。已查看截图确认呈现。
- `git diff --check` 通过。以上为构建、资源与样式样本验证，未在运行中的桌面真实会话验收，未重验应用内侧栏控件转移、全仓或跨平台行为。
