# Agent Note: 移除 Anybox Harness 项目侧栏的设备下拉框

Status: implemented

## 问题

项目侧栏底部常驻显示“这台电脑”。只有一个已保存设备时没有其他选项，多设备时设置弹窗已经提供相同的切换操作。

## 决策

从项目侧栏移除设备下拉框，设置按钮保留在右下角。用户可从“设置 → 会话设置”选择当前工作区的执行设备。

## 备选方案

仅在设备不足两台时隐藏下拉框，可为多设备用户节省一次点击。采用统一入口可以让两种情况下的侧栏布局保持一致。

## 影响与代价

多设备用户需要先打开设置再切换。设置沿用已有的草稿保护、设备选择记忆和路由恢复。Anybox Harness 应用包版本更新为 0.1.14。

## 验证

`npm run build` 通过，包括浏览器资源检查。连接界面、设置导航、工作区路由与包资源的 24 项定向测试通过。

macOS Chrome 使用正式页面和模拟设备响应验证了单设备与双设备场景。两种情况下均可从侧栏按钮打开设置。切换到第二台设备后，工作区路由和记忆的选择均指向新目标，弹窗恢复到原分类。此次未连接真实远端设备。
