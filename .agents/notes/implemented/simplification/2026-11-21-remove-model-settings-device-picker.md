# Agent Note: 移除模型管理内的设备选择器

Status: implemented

用户补图确认指的是列表滚动条。设备选择器已恢复。 [隐藏 Provider 和模型列表的滚动条](2026-11-21-hide-provider-list-scrollbars.md)

## 问题

模型管理内容区顶部仍显示“正在设置”的设备下拉框。用户要求移除该控件。

## 决策

两款应用在模型管理中直接展示 Provider 列表，设备随当前工作区。切到其他设置分类后，设备选择器按该分类的作用域显示。

## 备选方案

仅在单设备时隐藏会在多设备场景再次出现同一控件。模型管理统一使用工作区已经选定的设备。

## 影响与代价

涉及设置导航、焦点恢复与模型管理页眉间距。模型配置继续提交给当前设备，其他分类有独立切换入口。

## 验证

- 两款应用均通过 TypeScript 编译及浏览器静态资源检查。`node --test tests/models-client.test.mjs` 12 项全部通过。
- macOS Chrome 实测两款应用。模型管理的设备选择器及标签隐藏，Provider 列表从内容区原有内边距开始。选中 Provider 后读取当前设备的模型，常规分类恢复设备选择器，连接分类仍显示“所有设备”。桌面、320px 和 400px 视口下关闭控件与配置表单可用，模型管理区域保留可访问名称。
