# Agent Note: 合并设置弹窗的布局

Status: implemented

## 问题

设置弹窗上方有一整条只显示应用名称和关闭按钮的标题栏，把分类导航和内容推到下一行。用户希望设置界面作为一个整体。

## 决策

移除独立标题栏。桌面端的分类导航、内容和右侧关闭按钮使用同一布局。窄屏将关闭按钮放在横向分类导航的末端，并让内容使用完整宽度。原生弹窗通过可访问名称标识应用。

## 备选方案

仅缩短原有标题栏仍会保留独立的横条，因此把关闭操作放入现有设置布局。

## 影响与代价

涉及 Anybox Harness 和 Personal Agent 的设置弹窗模板及样式。关闭按钮使用已有原生弹窗和焦点恢复逻辑。

## 验证

- `node scripts/verify-web-assets.mjs` 与 `git diff --check` 通过。
- macOS Chrome 在桌面及 400px、320px 视口验证两款应用。工作区从弹窗顶边开始，关闭按钮和设备选择器无重叠，点击关闭和 Esc 都可返回。两款原生弹窗保留各自的可访问名称，模型管理仍能选择 Provider 并显示对应模型。
