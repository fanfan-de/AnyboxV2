# Agent Note: 先选择提供方的简约模型管理

Status: implemented

## 问题

模型管理会自动选中提供方并铺开配置、状态和模型信息。用户确认采用简约两列布局，进入时先看 Provider 列表，选中后再看对应模型。

## 决策

Anybox Harness 和 Personal Agent 统一采用 Provider 与模型两列。首屏左列展示已配置的提供方，右列只提示选择。显式选择后请求该提供方的模型清单，并在左列高亮当前项。模型行显示名称与需要处理的状态，搜索、API 设置和高级操作按需打开。

刷新保留仍有效的选择，移除后回到未选中列表。添加保存后选中新增提供方，取消时恢复进入添加前的选择。关闭设置或切换分类会清空选择和未保存的 Key，再次显式选择可继续编辑当前页面内的非秘密草稿。

## 备选方案

早期线框同时展示可用总数、逐行状态和展开的搜索框。用户反馈应进一步简约，最终确认压缩为选中态、模型名称和需要留意的状态。

## 影响与代价

两款应用分别更新设置导航与模型管理页面。用户可在“更多”中管理 API 设置、添加自定义模型、发现远端模型和刷新状态。模型设置、凭据、执行设备归属和后端接口沿用既有契约。
