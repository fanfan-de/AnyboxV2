# 变更方向记录协作约定

遵守[根协作说明](../../AGENTS.md)及[目录、格式和生命周期规则](README.md)。本目录保存每次独立变更的方向与理由。

- 开始修改前搜索相关记录；同一轮同一目标使用一篇，新的独立目标另建记录并链接相关项。
- 区分用户已确认的方向、协作者在授权范围内作出的实施决策与待讨论建议，不虚构用户确认；部分实现留在 `proposed/`，写明已完成和剩余项。
- 交付前将内容改为最终实际结果，记录实际检查及未验证范围，修正状态、文件路径和所有受移动影响的链接。
- `implemented/` 中路径、名称等实现事实随代码维护；方向被替代时另建记录，旧项保留原理由与替代链接，不改写成相反决策。
- 归档项只供历史参考，冻结后不修订；当前规则看根说明、活跃记录及组件手册。纠正归档事实另建记录并链接原项。
- 记录及规则自身的修订归入本轮目标记录，无需递归为每次记录编辑另建记录。
