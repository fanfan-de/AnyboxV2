# Agent Note: 宿主与单应用多语言试点优先

Status: proposed

实施进展：首个 Web 主流程已由[宿主与 Claude Agent 试点](../../implemented/feature/2026-11-12-host-claude-i18n-pilot.md)接入并完成本机验收；试点后的比较选择保留局部实现，其他入口与全量迁移仍待后续批次。本记录保留整个方向及剩余范围，实际交付与验证看实现记录。

## 问题

用户在评估通用 Nya 多语言组件的收益后，明确要求先不做 Nya 组件，将规划改为宿主和一个应用的中英文试点，再根据实际重复提取共享代码。此前设计已预设共享包、组件适配及较完整的生成/扫描工具链，超出了已证明的首期需求。

## 方向

已确认采用试点优先：宿主与应用各自持有资源和翻译实例，只通过只读语言偏好契约协作；首期不建设通用包、Nya 组件、服务键或来源提供方体系。局部初始化、查词、格式化和订阅释放先由所属界面实现，直接复用成熟库。

本轮规划沿用此前迁移优先级，选 Claude Agent 作为应用试点。先在浏览器完成一条可重复验收的流程：宿主选择语言、打开/切换应用，应用选择设备/既有项目、创建或打开会话、编辑草稿、发送/观察/完成或取消 Run，以及路径上的权限、错误与基础格式化。完整包管理、账号额度、详细工作区、桌面原生双入口、Anybox Harness、CLI 和应用声明式元数据另列后续范围，不以这些入口尚未迁移阻塞主流程试点，也不宣称已全部双语。

试点联合验收后，列出真实重复代码、调用方和差异，再决定是否提取。没有稳定重复则保留局部实现；即使提取也优先普通函数/实例工厂，不把 Nya 适配列为自动进入的下一阶段。轻量资源与类型检查随试点落地，JSON 转换、通用类型生成、AST 扫描器及翻译状态自动化按证据另行评估。

本轮完成规划修订，运行实现待后续独立变更。当前设计取代[早期治理安排](2026-11-12-i18n-governance.md)中预先共享与全面工具链的顺序；[Nya 组件候选](../../rejected/architecture/2026-11-12-i18n-nya-component.md)移为 rejected，表示本阶段不采用，保留原理由，不代表永久否定技术可行性。

## 备选方案

- 先建通用包及可选 `/nya` 适配：当前主要消费者不运行 Nya，已有 mount/dispose 足以持有订阅，提前增加公共 API 和依赖失效语义，不采用。
- 先做宿主、不验证应用接入：无法证明偏好契约、应用自治与资源独立发行在真实界面中成立，因此首批必须包含一个应用。
- 先完善全仓生成/扫描工具链：当前资源格式与迁移模式尚未通过试点，先做局部校验，后续按实际重复和遗漏补工具。

## 影响与代价

短期允许少量相似初始化代码存在，换取可核验的边界与实际抽取依据。偏好来源失败时保留最后语言或默认语言，不让 UI 依赖来源存活而退出；运行观察、草稿、机器字段及业务历史沿用原边界。本轮仅修改 Markdown 与记录状态，不新增代码、依赖、API 或运行行为。

## 验证

已核对当前设计、导航和三篇方向记录，移除共享包、Nya 适配及完整生成流水线的试点前置承诺，明确主流程及后续界面，并修正候选移动后的双向链接。Python 静态检查通过：5 个相关 Markdown 文件的 134 个本地链接目标存在，三篇记录的状态/目录及必备章节一致，无行尾空白；`git diff --check` 通过。

根 `npm run check` 已尝试，当前环境未在 PATH 提供 npm，命令以 127 退出，未进入构建或测试。本轮只交付规划修订，没有代码变更或浏览器/桌面运行验收。
